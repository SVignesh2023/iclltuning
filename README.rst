iclltuning
=====

**iclltuning** is a library that allows hyperparameter tuning of models fed to the ICLL (Imbalanced Classification via Layered Learning) model.

Acknowledgements
----------------

This package is based on and extends the implementation of Imbalanced Classification via Layered Learning (ICLL) model developed by Vitor Cerqueira and collaborators.

1. Link to the research paper of ICLL: `https://arxiv.org/pdf/2205.02553v1 <https://arxiv.org/pdf/2205.02553v1>`_
2. Python implementation of the original ICLL algorithm: `https://github.com/vcerqueira/experiments-icll <https://github.com/vcerqueira/experiments-icll>`_

A copy of the license is available in LICENSES/experiments-icll-BSD-3-Clause.txt.


Installation
------------

To install use:

.. code-block:: console

    $ pip install iclltuning


Requirements
------------

* pandas
* numpy
* scipy

Read the documentation at: `https://iclltuning.readthedocs.io/en/latest/index.html <https://iclltuning.readthedocs.io/en/latest/index.html>`_
